## AI 桥接现状（2026-11-11）

- 本机已安装 EasyEDA Pro API skill（WebSocket bridge，端口 49620–49629）。
- 扩展：`run-api-gateway.eext`（需在嘉立创 EDA 专业版中加载）。
- **能力**：经 bridge 执行 `eda.*` API，可读写工程/原理图/PCB 对象（以 API 文档为准）。
- **非能力**：生成描述文件或 JSON ≠ PCB 完成；未连接客户端时无法操作。

M2 首个任务应验证：health → 连接窗口 → 创建空工程 → 读写一个封装/网络。
