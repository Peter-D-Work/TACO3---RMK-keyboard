## 使用规则

1. 可用于列功能与大致丝印名称。
2. 不可用于生产封装尺寸、孔位、板厚推算。
3. 正反面镜像、焊盘坐标、USB 外伸、天线位置必须实物测量后写入 `hardware/interfaces/`。
4. BOOST 标注含义：充电电流选择（约 100mA → 300mA），仅当电池容量足够时使用；**不是升压电路**。
