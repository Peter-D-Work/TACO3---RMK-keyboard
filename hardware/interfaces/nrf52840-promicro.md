## 2. 排针（元件面朝上、USB 朝上）

每侧 **13 孔**，2.54 mm（外观）；第 1 排 B−/B+ 紧邻 USB。

| # | 左列 | 右列 |
|---|---|---|
| 1 | B−（电池负 / GND） | B+（电池正） |
| 2 | P0.06（D1 / TX） | RAW（卖家标 BATTERY+） |
| 3 | P0.08（D0 / RX） | GND |
| 4 | GND | RST |
| 5 | GND | VCC（3.3 V，受 P0.13 控制） |
| 6 | P0.17 | P0.31 |
| 7 | P0.20 | P0.29 |
| 8 | P0.22 | P0.02 |
| 9 | P0.24 | P1.15 |
| 10 | P1.00 | P1.13 |
| 11 | P0.11 | P1.11 |
| 12 | P1.04 | P0.10（NFC2） |
| 13 | P1.06 | P0.09（NFC1） |

第 2–13 排与 nice!nano v2 / Pro Micro 的 12 针排列一致。

## 3. 可用 GPIO 清单（交 PD-120）

共 **21 根**：侧边 18 + 中间 3。频率分类以 nRF52840 PS「Pin assignments」（Nordic 在线版，2026-11-11 查）为准（卖家图蓝/紫配色与之一致）：

- **高频可用**：无限制的普通 GPIO。
- **低频限定**：PS 标注 *Standard drive, low frequency I/O only*，信号 ≤ 10 kHz；靠近射频，超频使用会降低接收灵敏度。BLE 分体链路必须保住，按硬约束对待。

| 位置 | GPIO | 分类 | 备注 |
|---|---|---|---|
| 左列 | P0.06, P0.08 | 高频 | D1/D0（TX/RX 标注），可作普通 GPIO |
| 左列 | P0.17, P0.20, P0.24, P0.11 | 高频 | |
| 左列 | P0.22, P1.00 | 高频 | PS 推荐用途标 QSPI；本板未见外置 QSPI Flash（待核），作 GPIO 不受影响；P1.00 兼 TRACEDATA0/SWO |
| 左列 | P1.04, P1.06 | 低频 | |
| 右列 | P0.31, P0.29, P0.02 | 低频 | 兼 AIN7 / AIN5 / AIN0（电池 ADC 若走外部分压可选） |
| 右列 | P1.15, P1.13, P1.11 | 低频 | |
| 右列 | P0.10, P0.09 | 低频，**有条件** | 默认 NFC 天线脚；需 UICR `NFCPINS` 设为 GPIO（固件配置，PD-121 核对 RMK / embassy-nrf 写法）；两脚输出不同电平时两脚间漏电典型 1 µA、最大 10 µA（PS v1.9 `INFC_LEAK`），休眠前应置同一电平 |
| 中间 | P1.01, P1.02, P1.07 | 低频 | 位置见 §4 |

合计：**高频 8 根**（全在左列），**低频 13 根**。

不在排针上 / 禁用：P0.13（VCC 开关，§5）、P0.18（RESET）、P0.15（板载用户 LED，nice!nano 约定；本板待核）。

### 对 PD-120 的直接约束

需要高速边沿的信号只能放在 8 根高频脚上：

| 信号 | 频率 | 脚数 |
|---|---|---|
| PMW3610 SCLK + SDIO | SPI（MHz 级） | 2 |
| nice!view SCK + MOSI | 1 MHz（ZMK 设置） | 2 |
| SK6812 DIN | 800 kHz 数据流 | 1 |

这 5 根占掉 8 根高频脚中的 5 根。片选（NCS / CS）、MOT 中断、编码器、矩阵、背光使能等低速信号可放低频脚；PMW3610 NCS、nice!view CS 按事务翻转，是否放低频脚由 PD-120 按实际翻转频率判断。

## 4. 中间三脚与背面焊盘

| 项 | 本板（卖家图） | nice!nano v2（官方引脚图） |
|---|---|---|
| P1.01 / P1.02 / P1.07 形态 | **3 个通孔**，焊环与侧边排针相近 | 3 个小孔，明显小于侧边排针 |
| 排列 | 沿板宽一排，远离 USB 一端，约在第 12 排（P1.04 / P0.10）位置，略偏向板中心 | 同样在底端第 12 排附近一排 |
| 顺序（元件面朝上、USB 朝上，从左到右） | P1.01 → P1.02 → P1.07 | 同 |
| 横向位置（图像估计 ±1 mm） | P1.01 距左列约 3 mm，P1.07 距右列约 7 mm，孔距约 2.54 mm | P1.01 距左列约 2.5 mm，P1.07 距右列约 7.5 mm |
| SWD | 背面 4 个小焊盘 **VDD / DIO / CLK / GND**，靠右列第 10–12 排一侧 | 2 个焊盘 SWC / SWD，紧挨中间三脚 |
| B+ / B− | 第 1 排**全尺寸通孔**，与侧边排针同排同距 | 小孔，小于侧边排针 |
| BOOST 跳线 | 背面 RST/VCC 旁两个小焊盘 | 背面 RST 旁焊盘 |

结论：

- 图像估计下，中间三脚坐标与 nice!nano v2 相差在估计误差范围内（≤ 约 0.5 mm），**不能据此认定与 nice!nano 封装兼容**，也不能认定不同。孔径、SWD、B+/B− 孔型的差异是确定的。
- 中间三脚是通孔 → 可焊公排针接到我方 PCB 的 1×3 排母（是否采用由 PD-120 决定），比背面贴片焊盘飞线更可制造。
- 中间三脚全是低频脚，只适合矩阵 / 编码器 / 使能等低速信号。
- 坐标、孔径以到货卡尺为准（§8），1:1 打印对孔后才能进封装。

## 5. 电源与 nice!nano v2 差异清单

| 项 | 本板 | nice!nano v2 | 影响 / 状态 |
|---|---|---|---|
| 充电芯片 | 卖家只写「支持锂电池充放电」；图中丝印不可辨。同类 SuperMini 常见 LTH7R / TP4054 | BQ24072（带 Power Path） | **按无 Power Path 设计**（与左板一致）；USB↔电池切换实测转 PD-126 |
| 充电电流 | 100 mA，短接 BOOST → **300 mA**（卖家：仅电池 > 500 mAh） | 100 mA，BOOST → 500 mA | 电池选型按 300 mA 上限；BOOST 是充电电流跳线，不是升压 |
| 3.3 V LDO | 型号不可辨。同类板见 ME6217C33M5G、RT9013、TP2028、S2LC 标记等批次 | 未核（joric 记载的 AP2112K 属 v1） | 负载余量（nice!view + PMW3610 VDDIO + 其他 3.3 V 外设）到货后核 |
| VCC 外部电源开关 | **P0.13 置低 → 关闭 VCC 引脚 3.3 V**（卖家图） | P0.13 置低关闭（官方图） | 极性一致。nice!view 需常开 3.3 V，不接受控 VCC（见 `nice-view.md`）；SK6812 不从 VCC 取电 |
| VCC 关闭时漏电 | 早期批次上拉 5.6 kΩ → 关 VCC 时约 700 µA；2024-04 后批次改 10 MΩ / 500 kΩ+；部分晚期批次用普通硅二极管（约 60 µA vs 4 µA） | 约 20 µA 量级 | **本批未知**，休眠电流实测转 PD-126；不按卖家 20 µA 承诺续航 |
| 电池焊盘 | B+ / B− 为排针第 1 排全尺寸通孔；RAW 卖家标 BATTERY+ | B+ / B− 小孔；RAW 为 BATTERY+ | 电池可经排针（B+/B− 或 RAW/GND）进我方 PCB，不必焊背面；走哪组由 PD-120 定 |
| 电池电压检测 | 卖家未说明；同类板分压电阻未焊，读 VDDH；**USB 插入时 VDDH 被拉到约 5 V，充电时无法测电量** | 读 VDDH（BQ24072 输出，充电时 ≈ 电池 + 0.2 V） | 右手电量显示（nice!view）需接受「充电时读数无效」或外加分压到 AIN 脚（PD-120） |
| 板载 LED | 同类板 LED 颜色与 nice!nano 相反（红 = 用户 LED，蓝 = 充电），本板待核 | 蓝 = 用户（P0.15），红 = 充电 | 仅影响状态指示 |
| 32.768 kHz 晶振 | 同类板有晶振不良报告，可在固件改用内部 RC | — | PD-121 / PD-123 若遇 BLE 不稳先排查 |
| 刷固件后休眠 | 同类板报告刷写后需断电重启才能恢复深睡 | — | PD-126 测休眠电流前先断电重启 |

同类板的批次信息来自 joric nrfmicro wiki「Alternatives → SuperMini NRF52840」（2026-11-11 查询），**不是本批事实**。

## 6. 连接方式

- 主连接：侧边 2 × 13 排针 → 我方 PCB 母座（见 `connectors.md`）。母座用 1×12 还是 1×13（是否含 B+/B−）、中间 1×3 是否引出，由 PD-120 决定。
- SWD 小焊盘只作调试，不进主板连接。
- 天线端（远离 USB、与中间三脚同端）在我方 PCB 与外壳上需留净空，具体由 PD-129 / PD-130 处理。

## 7. 固件要点（交 PD-121 / PD-123）

- UF2 引导程序按 nice!nano v2 处理；`memory.x` FLASH 起始地址见 `docs/bringup/dev-machine-setup.md`，建工程时核对。
- P0.09 / P0.10 用作 GPIO 时，必须在固件中把 UICR `NFCPINS` 写为 GPIO。
- P0.13 的默认状态与 RMK 是否驱动它，在 PD-121 核对。
