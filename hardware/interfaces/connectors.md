# 开发板 / 模块连接约定

状态：**已确定**（Pete，2026-11-11）

## 规则

所有开发板与模块都用排针连接：

- **模块侧**：焊公排针（针脚焊在器件的板子上）。
- **我方 PCB**：放排母（母座），模块插上即可拆换。
- 不把模块直接焊死在主板上；不依赖模块背面焊盘（背面触点另行决策，见 PD-120）。

按键不属于开发板：Kailh 1350 轴体经热插拔轴座连接，见 `key-switch-backlight.md`。

## 堆叠高度（机械必须跟踪）

模块离主板的高度 = 排母高度 + 公排针塑料座高度，直接影响：

- 屏幕表面到外壳面板的距离；
- **PMW3610 镜头到轨迹球表面的光学距离**（目标 2.2–2.6 mm，见 `pmw3610-module.md`）；
- 外壳总厚度。

排母型号（标准高 / 矮型）未选，高度按所购型号实测后写入本表与 `mechanical/`。
