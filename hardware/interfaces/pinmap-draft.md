## ESP32-S3FH4R2（假定）分类

| 类别 | GPIO | 说明 |
|---|---|---|
| 可用（优先正面） | 1–13（注意 3 为 strapping 相关） | 正面常见排针；功能多复用 |
| 可用（背面焊盘常见） | 14–18, 21, 33–38, 39–42, 45–47 | 33–37 在 **Quad** Flash/PSRAM 封装上通常空闲；39–42 默认 JTAG |
| UART0 排针 | 43=TX, 44=RX | 上电可能有 ROM 日志 |
| 板载占用 | 48 | WS2812 + 常有同脚状态 LED |
| 禁止 | 19, 20 | USB D−/D+ |
| 禁止 | 26–32 | 封装内 Flash/PSRAM |
| 启动敏感 | 0, 3, 45, 46 | 下载模式 / JTAG 源 / VDD_SPI / 启动与日志 |
| 不存在 | 22–25 | S3 无此 GPIO |

## 左半功能预算（逻辑需求，脚位未分配）

| 功能 | 估测脚数 | 备注 |
|---|---|---|
| 键矩阵 | 视键数；二极管矩阵 rows+cols | 键数未冻结 → 预算留余量 |
| 编码器 A/B | 2 | 建议有内部上拉 |
| 编码器按压 | 1 或并入矩阵 | |
| GC9A01 SPI | SCLK, MOSI, CS, DC, RST（± BLK） | 无 MISO；优先带 BLK 模组以便 PWM 熄屏 |
| 屏幕背光 PWM | 1（若有 BLK） | 与按键背光分开 |
| 按键背光 PWM | 1（+ MOSFET） | RMK 无现成背光 → 自定义 |
| 电池 ADC | 1（ADC1 优先） | 分压电路待定 |
| 电源控制（可选） | 0–1 | Power Path / 负载开关若外挂 |
| 预留调试 | TX/RX 或 USB-JTAG | 不要占光全部排针 |

> 正面常规 GPIO 可能不足。决策顺序：背面焊盘转接板 → 少量飞线 → I/O 扩展器。

## 电源预算（草案）

| 轨道 | 预期 | 风险 |
|---|---|---|
| 左 3V3 | 板载 LDO 输出 | 屏背光+矩阵+S3 峰值；LDO 型号待核实 |
| 左 5V 排针 | **≈ USB VBUS**；电池供电时可能≈电池电压 | 不能当稳定 5V 外设源 |
| 左 B+/B− | 电池；充电 100/300 mA（BOOST） | 无保护板需外加；非 Power Path |
| 右 3V3 / VCC | LDO；P0.13 可关外部负载 | 早期克隆漏电问题需按批次核实 |
| 续航 | 禁止无实测承诺小时数 | 记录 idle / 交互 / 熄屏 / 休眠电流 |
