# 引脚与接口草案（未冻结分配）

左板板级事实：见 **`esp32-s3-super-mini.md`**（PD-118，资料级）。  
本文件保留**功能预算**；具体 GPIO 分配在 PD-120 决定后冻结。

**卖家图不是已验证原理图；封装尺寸不得按图片比例推算。**

## 左板连接基线

- 侧边 **2×9 排针**接主板；排针信号 15 根：GPIO1–13 + TX(43)/RX(44)。
- 有条件：GPIO3（strapping）、43/44（UART0 ROM 日志）。
- 背面触点（可用 GPIO14–18/21/33–42/47；有条件 0/45/46；B+/B−）待 PD-120 决定引出方式。

## 左半功能预算（逻辑需求，脚位未分配）

| 功能 | 估测脚数 | 备注 |
|---|---|---|
| 键矩阵 | 视键数；二极管矩阵 rows+cols | 键数未冻结 → 预算留余量 |
| 编码器 A/B | 2 | 建议有内部上拉 |
| 编码器按压 | 1 或并入矩阵 | |
| GC9A01 SPI | SCL, SDA, RES, DC, CS | 无 MISO；模块见 `gc9a01-tft.md` |
| 屏幕背光 BLK | 1 | 已选 8 针带 BLK 模块；PWM 调光 / 熄屏 |
| 逐键背光 SK6812 DIN | 1 | 单线串行；S3 用 RMT；见 `key-switch-backlight.md` |
| 背光电源使能 | 1 | 高边负载开关，切断 1 mA/颗静态电流 |
| 电池 ADC | 1（ADC1 优先，GPIO1–10） | 分压电路待定；电池在背面 B+ |
| 电源控制（可选） | 0–1 | Power Path / 负载开关若外挂 |
| 预留调试 | TX/RX 或 USB-JTAG | 不要占光全部排针 |

> 非矩阵外设约 11 根（屏 6 + 编码器 2 + 背光 DIN 1 + 背光使能 1 + 电池 ADC 1）→ 排针只剩约 4 根给矩阵，不够。补齐方式由 PD-120 决定：背面焊盘转接 / 飞线 / 扩展器或移位寄存器。

## 右半功能预算（脚位未分配）

右板板级事实与 21 根可用 GPIO 清单：见 **`nrf52840-promicro.md`**（PD-119，资料级）。其中只有 **8 根高频脚**（P0.06/08/11/17/20/22/24、P1.00，全在左列）；其余 13 根为 nRF52840 规定的低频脚（≤ 10 kHz）。PMW3610 SCLK/SDIO、nice!view SCK/MOSI、SK6812 DIN 共 5 根必须放高频脚。

| 功能 | 估测 | 备注 |
|---|---|---|
| 键矩阵 | rows+cols | |
| 编码器 A/B + SW | 2–3 | |
| PMW3610 | SCLK, SDIO, NCS, MOT，（NRESET 可选） | SDIO=MOSI=MISO；模组见 `pmw3610-module.md` |
| nice!view | MOSI, SCK, CS = 3 | 只写 SPI，独占引脚，不与 PMW3610 共线；CS 高有效；VCC 接常开 3.3 V；见 `nice-view.md` |
| 逐键背光 SK6812 DIN | 1 | nRF52840 用 PWM/I2S 序列驱动 |
| 背光电源使能 | 1 | SK6812 需 ≥ 3.7 V，**不能**用 P0.13 控制的 3.3 V VCC 供电 |
| 电池 | VDDH 或 ADC 脚 | 同类克隆板分压未焊、读 VDDH；USB 插入时 VDDH≈5 V，充电时测不了电量；外加分压可用 AIN 脚 P0.31/P0.29/P0.02 |

> 非矩阵外设约 11 根（PMW3610 4 + nice!view 3 + 编码器 2 + 背光 DIN 1 + 背光使能 1；PMW3610 NRESET 另计）。侧边排针 18 根 → 矩阵约 7 根；中间 P1.01/P1.02/P1.07（本板为通孔，可焊排针）也用则约 10 根。P0.09/P0.10 为 NFC 脚，需固件配置为 GPIO。中间三脚坐标与 nice!nano v2 是否一致须到货卡尺（见 `nrf52840-promicro.md` §4）。

## 电源预算（草案）

| 轨道 | 预期 | 风险 / 核验 |
|---|---|---|
| 左 3V3 | 板载 LDO 输出 | LDO 型号与负载余量待测 |
| 左 5V 排针 | ≈ USB VBUS；电池供电时可能≈电池电压 | 不能当稳定 5V |
| 左 B+/B− | 背面焊盘；充电 100/300 mA（BOOST） | 无保护板需外加；按无 Power Path 设计，实测转 PD-126 |
| 右 3V3 / VCC | LDO；P0.13 置低关闭 VCC | 早期克隆批次关 VCC 时约 700 µA 漏电，本批未知（PD-126）；nice!view 需常开 3.3 V（VCOM 持续翻转），不接受控 VCC |
| 两侧 SK6812 电源 | 3.7–5.5 V；不从 3V3 LDO 取电 | 锂电低电量低于下限；静态 1 mA/颗需负载开关；峰值 36 mA/颗需限亮度（PD-120） |
| 续航 | 禁止无实测承诺小时数 | 记录 idle / 交互 / 熄屏 / 休眠电流 |
