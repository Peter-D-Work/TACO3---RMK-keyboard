# 里程碑与依赖

| 里程碑 | 依赖 | 通过条件 | 可并行 |
|---|---|---|---|
| **M0** 选型与底座 | — | 选型表无未解释冲突；仓库底座就绪；BOM/引脚预算草案 | 外观草模（Pete） |
| **M1** 开发板最小联调 | M0 板型与 RMK rev 冻结 | 同一固件版本：右键/旋钮/球 → BLE → 左 → PC HID；圆屏+背光并发不卡顿；USB/电池切换不复位；有电流记录 | 早期外壳外形迭代 |
| **M2** 接口冻结与 PCB | M1 通过；接口/封装冻结 | pinmap 一致；ERC/DRC；可审阅 Gerber/BOM | — |
| **M3** 模型与打印试装 | M2 外形/高度输出 | USB/插座/屏/旋钮/球/电池/线材可装配 | 与 M2 末期可部分重叠（假板） |
| **M4** 打板前冻结 | M1+M2+M3 | 阻塞清零；下单资料包；**Pete 下单** | — |
| **M5** PCB 到板验证 | M4 到货 | 供电与功能复测记录 | — |
| **M6** 总装与发布 | M5 | 可重复构建/烧录/组装；发布说明与已知问题 | — |

硬门槛：**不得在 M1 通过前定版下单 PCB。**
